How scoring works

Every match has exactly three sets. Each set won earns 2 league points, so a 3–0 result awards 6–0 points and a 2–1 result awards 4–2 points. Games For and Games Against add up every game across all three sets. Rankings are decided by points, then games difference, then games for.
